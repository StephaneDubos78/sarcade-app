# UX communication v0.1

Depuis la carte, l'opérateur accède aux Messages et à la Main courante.

Messages :
- réception WebSocket message.created
- persistance locale
- émission Offline First
- priorités routine / urgent / immediate
- ACK reçu / lu / accepté / refusé
- badge du nombre d'opérations en attente de synchronisation

Main courante PCO :
- messages et ACK chronologiques
- rafraîchissement manuel V0.1
- identité de l'acteur et heure locale

Prochaine évolution : filtres, recherche, destinataires équipe/utilisateur, notifications locales, ACK automatiques configurables et rafraîchissement temps réel de la main courante.
